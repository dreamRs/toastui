# Clear selection from calendar with Proxy

Removes all date/time selection elements currently displayed in the
calendar.

## Usage

``` r
cal_proxy_clear_selection(proxy)
```

## Arguments

- proxy:

  A
  [`calendar_proxy()`](https://dreamrs.github.io/toastui/reference/calendar_proxy.md)
  `htmlwidget` object.

## Value

A `calendar_proxy` object.

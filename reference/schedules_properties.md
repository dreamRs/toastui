# Schedules properties

This dataset contains properties that can be use to create schedules in
[`calendar()`](https://dreamrs.github.io/toastui/reference/calendar.md).

## Usage

``` r
schedules_properties
```

## Format

A `data.frame` with 26 rows and 3 variables:

- Name:

  Name of property

- Type:

  Type

- Description:

  Description

## Source

Toast UI documentation
(<https://nhn.github.io/tui.calendar/latest/EventObject/>)

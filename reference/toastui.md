# HTMLwidget interface to the [TOASTUI](https://ui.toast.com/) javascript libraries.

Create interactive tables, calendars and charts with one package.

## Tables

Interactive and editable tables with
[tui-grid](https://ui.toast.com/tui-grid/), see
[`datagrid()`](https://dreamrs.github.io/toastui/reference/datagrid.md).

## Calendars

Interactive and editable calendars with
[tui-calendar](https://ui.toast.com/tui-calendar/), see
[`calendar`](https://dreamrs.github.io/toastui/reference/calendar.md).

## Charts

Interactive charts with [tui-chart](https://ui.toast.com/tui-chart/),
see [`chart`](https://dreamrs.github.io/toastui/reference/chart.md).

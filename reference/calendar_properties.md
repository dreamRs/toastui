# Calendar properties

This dataset contains properties that can be used to set calendars
properties in
[`cal_props()`](https://dreamrs.github.io/toastui/reference/cal_props.md).

## Usage

``` r
calendar_properties
```

## Format

A `data.frame` with 6 rows and 3 variables:

- Name:

  Name of property

- Type:

  Type

- Description:

  Description

## Source

Toast UI documentation
(<https://nhn.github.io/tui.calendar/latest/CalendarInfo/>)
